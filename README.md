# projet-python-ds

Voir le [site du projet](https://gaybrice.github.io/projet-python-ds/notebooks/main.html)

Pour reproduire le rendu du html :
```
cd projet-python-ds
uv sync
uv run quarto render
```

Pour mettre à jour le site :
```
cd projet-python-ds
uv sync
uv run quarto publish gh-pages
```
